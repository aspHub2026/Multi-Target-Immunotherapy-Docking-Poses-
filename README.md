This file contains the 3D diagrams from molecular docking involving caspase-1, TNF-alpha, TLR7, and TLR8. You should unpack the file. There are four folders, each belonging a protein. Each protein is complexed with four ligands: 1) reference ligand, 2) ChEMBL molecule with an experimentally determined activity value, 3) the de novo designed molecule MTIMD-02, 4) the de novo designed molecule MTIMD-04. Therefore, within each folder of a protein, you can find four files in *.dsv format; they can be visualized using the Discovery Studio Visualizer version 19.1 (or higher).
